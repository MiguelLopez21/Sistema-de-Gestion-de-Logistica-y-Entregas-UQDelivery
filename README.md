# UQDelivery - Sistema de Gestión de Logística y Entregas

El objetivo de este proyecto es diseñar, documentar, desarrollar y probar una aplicación web completa para la gestión de envíos y entregas de paquetes en entornos urbanos.

## Requisitos

- Java 17 o superior
- Maven (incluido mediante `mvnw`, no hace falta instalarlo)

## Ejecutar el proyecto

```bash
./mvnw spring-boot:run
```

En Windows también puedes usar `mvnw.cmd spring-boot:run`, o ejecutar la clase `UqDeliveryApplication` desde IntelliJ.

## Tecnologías

- Spring Boot 4.1.2
- Spring Data JPA
- Spring Security
- Spring Validation
- Base de datos H2 (en memoria)
